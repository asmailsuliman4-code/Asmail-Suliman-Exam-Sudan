# 📚 مكتبة الأستاذ إسماعيل سليمان حسن
## مكتبة المناهج والامتحانات السودانية

الهدف: توفير مرجع إلكتروني متكامل لطلاب ومعلمي السودان، يجمع بين المقررات الدراسية والامتحانات النموذجية المعتمدة.

### 📥 محتوى المكتبة:
- كتب وملخصات المرحلة المشتركة الكبرى
- امتحانات ومراجعات المرحلة الثانوية بجميع فروعها
- نماذج اختبارات وفق معايير وزارة التربية والتعليم السودانية
- مواد تعليمية من إعداد وتأليف الأستاذ إسماعيل سليمان حسن

### 📍 المصدر والاعتماد:
جميع المحتويات متوافقة مع المنهج السوداني، مقدمة من **مدرسة النبراس الثانوية الخاصة – كنانة / أبوتقابة – ولاية النيل الأبيض**
